In-tree plugins

12 registered

Trusted by construction — they arrived with weave itself, so whoever could modify them could modify weave. That is a real trust statement, not a loophole.

Install a pack
  1. weave plugin add <path>

    Copies a folder containing plugin.json into ~/.weave/plugins. Needs a restart to load.

  2. weave plugin manifest <dir>

    Generates the integrity block. Without it nothing can produce a package the loader accepts.

  3. weave plugin trust <dir>

    Pins the digest against the identity in the operator's trust store.

  4. weave plugin list

    Confirms it registered and shows what it contributes.
