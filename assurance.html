Standing proof

Proven, not promised.

Every guarantee weave makes maps to enforcement that runs — seeded chaos storms over real replicated substrates on every CI pass, byte-mutation fuzzing of every hand-rolled wire parser, an exhaustive auth-boundary sweep, a long-horizon soak, and a one-command acceptance drill against the live fleet. The drill writes its verdict into the replicated log itself, so the proof travels with the fleet: any host answers weave drill --history, and a node that joins tomorrow inherits the record of every roll before it.

Seven claims, each with its enforcement.

a claim without a row here is treated as unproven · boundaries stated, never hidden
chaos storms · live drill

A task settles exactly once

Three real replicated substrates under seeded fault storms — partition flaps, restart storms, wobbly links. Any failure replays from a single seed.

Stated boundary: work fully run on both sides of an open partition dual-records; the folds still settle one winner identically on every host — asserted, not assumed.

chaos · drill phase 1

A halt reaches everything

One appended event stops claiming on every host, including ones nobody can reach. Free local peers ride through cause-tagged stops; a failing backend halts itself and names the recovery verb.

verdict-shared ceilings

Budgets stop runaways — dollars and tokens

Fleet-window, mid-burn per-task abort, fan-out tree bounds, per-schedule-run, and token ceilings all trip the same replicated halt. A $0 subscription turn still lands its full token weight.

two-peer dedup · the soak

Schedules fire exactly once per window

Fleet-fired with no elected scheduler: every peer computes the same window, dedup lands one declaration. The soak samples a one-minute schedule for days; healthy is window-lag 0–1, forever.

320-probe sweep

The console has no unauthenticated side door

Every path × method × bad credential lands in the closed set. Only liveness and the login door answer without credentials; refusals carry no detail; passkey ceremonies are exercised by a synthesized authenticator.

seeded fuzz storms

The wire parsers cannot be crashed from the network

Bit flips, truncations, splices and noise over the CBOR, DNS-SD and chunked-transfer parsers: a value or a clean error, never a hang, never a structure that lies about itself.

channel binding · convergence

Replication is encrypted and converges

TLS with secret-bound channel binding — an interloper without the secret cannot vouch for its certificate. After any partition heals, every host holds the same events.
