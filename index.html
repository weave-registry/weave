The substrate

One append-only log. Everything else reads from it.

There is no scheduler handing out jobs. There is a log, and there are peers watching it.

  1. Declare

    A goal enters through the gateway — the single write path — optionally pinned to a persona so only that specialist can take it.

  2. Claim & lease

    Peers poll, race, and one wins. The winner renews a 60-second lease every 30 seconds for as long as it is working.

  3. Publish

    Tool calls, progress, and board panels stream back as events. Every surface watching the log sees them at the same moment.

  4. Settle & recall

    Results survive log compaction. Any peer can pull an old result back with recall_task instead of re-running the work.

The fleet

Machines join with a secret. Everything else is automatic.

Addresses are discovered, identity persists, the wire encrypts itself, and every dollar has a ceiling. Configuration is one shared secret — because membership is the secret.

$ weave up --daemon discovery: mdns found max · bazzite replication: following https://… (tls)

Three commands to join

Export the secret, pick your scope, weave up. mDNS finds the fleet, one link makes itself bidirectional, and the newcomer syncs exactly the history it is missing. Restart it ten times — it is the same peer ten times.

channel verified HMAC(secret, sha256(cert)) · per connection

Encrypted by default

Replication speaks TLS with a self-signed cert the shared secret vouches for — verified against the certificate each dialer actually observed. No CA, no pinning, no first-contact window. An interceptor simply fails.

fleet $25/24h · task $2 · tree $10 · local $0 ceilings on by default · free backends exempt

Money is an invariant

A rolling fleet budget, a per-task tripwire that aborts mid-turn, and a lifetime budget per spawn tree — fan-out multiplies tasks, never allowances. Backends declare how they bill, and per-token ones are never auto-selected over your subscription or a free local model.

Where it is

Decided in writing, shipped in slices, drilled live.

Sixty-five architecture decision records, each written before its code. The invariants are not just unit-tested — they are drilled on a live multi-machine fleet: halt the board, declare N tasks, resume so every peer pounces at once, and count N completions.
